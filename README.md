1. Download [Solara](wearedevs.net/d/Solara).

2. Install Solara

3. Copy this and paste in Solara:
```
loadstring(game:HttpGet("https://raw.githubusercontent.com/XoliwierX7/RubikWare/main/ver3.lua", true))()
-- You can use older versions too!
```

4. Click "Start" Button and boom!
